# Ticket Booking Management System

A full-stack travel and booking management platform developed as part of the System Analysis and Design (SAD) Lab at United International University (UIU).

The system provides an integrated solution for booking buses, rental cars, hotels, and travel services within a single platform.

The project follows structured software engineering practices including system analysis, software design, testing methodologies, and team-based development workflows.

---

## Branch Structure

### main
Frontend application containing UI components, booking workflows, and user interaction features.

### master
Backend system including REST APIs, authentication, database operations, and core business logic.

### carRent
Dedicated car rental module including vehicle listings, availability management, and rental booking system.

---

## Project Features

### Multi-Service Booking System
- Bus ticket booking
- Car rental service
- Hotel reservation system
- Unified booking and tracking system

### Role-Based Access Control (RBAC)
- Separate roles for Users and Admins
- Secure authentication and authorization
- Controlled access to system features

### Booking Lifecycle Management
- Create, update, and cancel bookings
- Real-time availability tracking
- Booking confirmation and history management

### Admin Dashboard
- Manage users and bookings
- Monitor system activity
- Handle notifications and logs

### Map API Integration
- Route visualization
- Location-based services
- Travel route and destination support
